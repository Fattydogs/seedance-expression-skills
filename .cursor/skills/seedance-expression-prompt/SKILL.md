# Seedance 2.0 人物表情精准提示词

将用户的大白话/感性描述，翻译成 **可执行的面部肌肉指令 + 时序分镜**，供即梦 Seedance 2.0 直接使用。禁止只输出「开心」「难过」「震惊」等抽象情绪词。

## 核心原则

| 问题 | 做法 |
|------|------|
| 模板化假笑/假哭 | 用肌肉分区 + 强度数值，不用情绪形容词堆砌 |
| 塑料脸 | 强制写入非对称与微瑕疵 |
| 说话嘴型假 | 单独写口部肌群与帧级开合度 |
| 表情一整段不变 | 按秒/按句写表情关键帧弧线 |

## 工作流程

### Step 0：收集输入（缺则推断，勿反复追问）

从用户消息提取或合理默认：

- **角色**：是否已有 `@图片` 面部参考；写实/动漫/3D
- **时长**：默认 5s；用户指定则用其值
- **是否说话**：有台词/旁白 → 启用「说话肌群 + 唇形同步」块
- **镜头**：默认胸上特写或面部特写；用户有运镜则保留
- **原始意图**：用户原话（感性描述）保留在输出末尾「意图对照」一行

### Step 1：解析感性描述 → 结构化意图

填写内部表（不省略逻辑，最终可摘要进输出）：

```
[场景触发] 什么事件导致表情变化
[表情目标] 用户想要观众感受到什么（一句话）
[强度] 微妙(1-3) / 中等(4-6) / 强烈(7-9) / 夸张表演(10)
[持续] 一闪而过 / 保持 / 渐变消退
[说话] 是/否；若有，摘录台词或语气（急促/哽咽/冷笑）
```

### Step 2：情绪三层叠加

为每一层写 **1–2 句肌肉化描述**（不用单独写「我很伤心」）：

| 层级 | 含义 | 写法要点 |
|------|------|----------|
| **L1 底色** | 性格/长期状态（疲惫、警惕、温和） | 基线肌群张力：眉间、眼裂、嘴角默认位置 |
| **L2 情境** | 当前剧情情绪（委屈、得意、心虚） | 主表情肌群激活组合 |
| **L3 社交面具** | 想藏/想装/强撑（强颜欢笑、故作镇定） | L2 与 L1 的 **矛盾肌群**：例如 L2 嘴角上扬但 L3 眼轮匝肌不放松 |

三层必须在提示词里 **同时出现**，并标明冲突（若有）：「嘴角上扬 4/10，但眼轮匝肌仍保持 6/10 紧缩，形成强撑的笑」。

### Step 3：肌肉分区精准控制

使用 [muscle-atlas.md](muscle-atlas.md) 中的分区 ID 与术语。每个相关分区标注：

`分区名 | 动作方向 | 强度0-10 | 持续时间或起止帧`

**必填分区**（按表情调整增减）：

- 眉区：额肌、皱眉肌、降眉间肌
- 眼区：眼轮匝肌（眶部/睑部）、睑裂开合
- 颧区：颧大肌、颧小肌、提上唇肌
- 鼻唇区：鼻肌、口角提/降肌
- 口区：口轮匝肌、颏肌、下唇方肌
- 颈辅助：颈阔肌（仅强烈情绪）

**禁止**：仅用「眼睛变大」「笑得很开心」代替上述条目。

### Step 4：非对称性 + 瑕疵控制

每条提示词 **至少包含 3 项**（从下列库中选，与表情逻辑一致）：

- 左右眉高度差 1–3mm 或强度差 ≥2 级
- 单侧嘴角更高/更紧（注明左或右）
- 眨眼：左眼先闭 2–4 帧，或左右闭合幅度差
- 微颤：下唇/口角 0.5–1Hz 极轻颤（紧张、克制）
- 瞳孔/视线：一眼略偏，打破「直视镜头」对称
- 皮肤微动：鼻翼单侧扩张、单侧法令纹更深
- 时序瑕疵：表情先起于一侧再传导至另一侧（延迟 3–8 帧）

用自然语言写入 Seedance 提示词，例如：「右侧颧肌先抬起，左侧延迟约 0.1 秒跟上，嘴角不对称，右高左低约 15%」。

### Step 5：说话专属 + 帧级时序

**若角色说话**（或 `@音频` 唇形同步）：

1. 引用 [muscle-atlas.md](muscle-atlas.md)「说话肌群」：口轮匝肌、颏肌、下颌开合、颊肌
2. 按 **台词分句或按秒** 写口型意图（不必 IPA，用中文口型描述即可）：
   - 开口度：闭 / 微张 / 半开 / 大开
   - 唇形：扁唇、圆唇、咧嘴、噘嘴
   - 下颌：静止 / 轻微下拉 / 明显下拉
3. **表情与口型解耦**：嘴在动的同时，眉/眼/颧仍保持 L1–L3 张力，避免「说话脸」重置为中性

**帧级时序**（时长 T 秒，按 1s 一格或用户指定节点）：

```
0.0–X.Xs：[肌群快照 + 运镜]
X.X–Y.Ys：[变化弧线：从 A 状态过渡到 B，注明主导肌群]
...
```

变化须写 **过渡动词**：「缓升」「骤收」「僵住 0.3s 后崩塌」「先抑后扬」。

### Step 6：组装 Seedance 2.0 成品提示词

按以下 **固定区块** 输出（用户可复制到即梦）。语言：中文为主，肌肉名可用中/英并列一次。

```markdown
## Seedance 2.0 表情提示词

### @ 引用（按需保留/删除）
- @图片1：角色面部基准，保持五官身份一致
- @音频1：（若有）唇形与语气同步，微表情不抢戏

### 镜头与画面
[景别、角度、景深、光照对面部的影响]

### 表情·肌肉指令（核心）
**L1 底色：** …
**L2 情境：** …
**L3 面具/矛盾：** …

**分区激活表：**
- [分区]：[方向+强度/10] …
（列出所有相关分区）

**非对称与瑕疵：**
- …
- …
- …

### 说话与口部（若无说话则写「本段无对白，口部保持 L2 默认张力，无夸张张嘴」）
[分句或分秒口型 + 下颌]

### 帧级表情时序（总长 Xs）
| 时间段 | 面部状态 | 主导变化 |
|--------|----------|----------|
| 0.0–… | … | … |

### 连贯动作与运镜（可选）
[与表情协同的身体/镜头，避免全身大动抢面部]

### 音频/氛围（可选）
[BGM、环境音、语气词]

### 负面约束（必写）
不要：对称标准微笑、漫画式大眼、整块脸同时变形的橡皮脸、无眨眼、牙齿全程外露、与 L3 矛盾的纯开心脸。

### 意图对照
用户原意：「…」→ 已拆解为上述肌肉与时序指令。
```

### Step 7：自检清单（输出前默念）

- [ ] 是否 **零** 单独使用「很开心/很伤心/震惊」而无肌肉对应？
- [ ] L1/L2/L3 是否齐全且冲突有写清？
- [ ] 是否 ≥3 条非对称/瑕疵？
- [ ] 是否有分段时间表？
- [ ] 说话场景是否写了口型与表情并行？
- [ ] 是否含负面约束？

## 感性词 → 肌肉化速查

| 用户常说 | 优先肌群与参数提示 |
|----------|-------------------|
| 尴尬 | 颧肌轻度(3)、口轮匝肌牵张、视线偏开、单侧挑眉 |
| 强颜欢笑 | 颧大肌(4–5) + 眼轮匝肌眶部不放松(5–6)、颏肌紧张 |
| 心虚 | 眼神水平快扫、口角不对称微拉、吞咽(喉结/颈阔肌轻收) |
| 憋笑 | 口轮匝肌压唇、鼻肌皱、眼轮匝肌睑部挤压、肩颤可选 |
| 失望 | 颧肌释放、降口角、上睑下垂 2–3mm、呼气口型 |
| 愤怒克制 | 皱眉肌(6–7)、眼裂缩、口轮匝肌抿紧、下颌咬紧不开口 |
| 释然 | 眉间释放、长呼气口型、眼轮匝肌缓慢放松、口角对称微扬 |

完整映射见 [muscle-atlas.md](muscle-atlas.md)。

## 与通用 Seedance 技能的关系

本技能 **只负责面部微表情与口型时序**。运镜、场景、服装、特效仍可用项目内其他 Seedance 提示词规范拼接；拼接时把本技能输出的「表情·肌肉指令」和「帧级表情时序」块 **原样嵌入** 总提示词，不要改写成感性描述。
