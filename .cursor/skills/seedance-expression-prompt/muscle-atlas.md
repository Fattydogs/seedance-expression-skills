# 面部肌肉分区图谱（Seedance 表情提示词用）

供 `seedance-expression-prompt` 引用。提示词中写 **中文肌肉名 + 可选英文**，并附 **强度 0–10** 与 **方向/对称性**。

## 强度标度

| 等级 | 视觉效果 |
|------|----------|
| 0 | 完全放松，不参与 |
| 1–2 | 仅可察觉，近特写可见 |
| 3–4 | 自然日常微表情 |
| 5–6 | 清晰可读的中等表情 |
| 7–8 | 强烈情绪，略夸张仍可信 |
| 9–10 | 舞台/喜剧夸张，慎用 |

## 说话专属肌群（Speech Stack）

与 L1–L3 **并行**，不可因张嘴清空眉眼张力。

| 要素 | 控制要点 |
|------|----------|
| 句首 | 下颌是否先落再发音；唇形预形（圆唇/扁唇） |
| 句中 | 开口度随音节变化；颊肌随元音轻鼓 |
| 句尾 | 闭口方式：骤然闭合 / 渐闭 / 微张残留气声 |
| 协同表情 | 例：哭着说话 → 眶部 6/10 全程，口型随词变化但颧肌不假装高兴 |

**口型中文描述词库**（替代 IPA）：

- 闭唇、微启、半开、大开、扁唇咧、圆唇噘、上齿轻咬下唇、嘴角单向牵拉

## 常见组合（情绪三层 → 肌群）

### 真笑（Duchenne）

- M1 5–7 + U4 4–6；U5 仅在高强度真笑
- 避免：仅 M1 10 而 U4/U5 为 0（假笑）

### 假笑/社交笑

- M1 4–5 + U4 0–2 + U5 0；可选 L3：眼神无挤压
- 加瑕疵：右 M1 比左高 2 级

### 悲伤

- P3 4–6 + U6 上睑下垂 + M1 释放至 0–1
- L1 底色：整体低张力

### 愤怒（克制）

- U2 6–7 + U6 缩小 + P1 抿 6 + L2 咬 4；口部可闭着说话前吸气

### 恐惧/惊讶

- U1 提 + U6 张大 + P1 口型圆（惊讶）或 U5+P1（恐惧眯眼）

### 厌恶

- M3 + M5 + U3 + 单侧 M4

### 轻蔑

- 单侧 P2 或 P3 + 单侧 U4 眯眼 + 视线偏转

## 非对称写法模板

```
[左/右][肌群ID] [强度]，对侧 [强度±Δ]，传导延迟 [N] 帧
```

示例：

- 右 U2 5/10，左 U2 2/10，眉间皱褶偏右
- 左 M1 6/10，右 M1 3/10，延迟 4 帧后右侧微抬
