# 表情提示词示例（感性输入 → Seedance 成品）

## 示例 1：尴尬又不失礼貌

**用户输入：**「就是那种社交场合尴尬又想保持礼貌的笑，别太假。」

**输出摘要（完整结构见 SKILL.md 模板）：**

### 表情·肌肉指令

- **L1 底色：** 社交警觉，U2 基线 2/10，睑裂正常
- **L2 情境：** 尴尬，M1 仅 3/10，P1 牵张 4/10
- **L3 面具：** 礼貌微笑，M1 试图升至 5 但 U4 仅 1/10（无真笑挤眼）

**分区：** U2 3/10；M1 左4右2；U4 1/10；P1 4/10；视线 5° 偏右下，避免直视

**瑕疵：** 右 M1 先动，左延迟 0.12s；一次不完整眨眼（左闭 70%）；颏肌 2/10 轻紧张

### 帧级（5s）

| 0.0–1.0s | 礼貌凝视，微抿 | U2 从 2→3 |
| 1.0–2.5s | 「笑」起，不对称 | M1 右升 |
| 2.5–4.0s | 笑僵 0.4s | 眼无挤压 |
| 4.0–5.0s | 笑收，回归抿唇 | M1 回 2 |

**负面约束：** 不要八颗牙标准笑、不要双眼弯成月牙。

## 示例 2：边说边忍哭

**用户输入：**「她一边强撑着安慰朋友一边说话，声音在抖，5 秒，有台词：没事的，都会好起来。」

### 说话与口部

- 0.0–1.2s：「没事的」— 微张口型，下颌轻颤，P1 收 5/10 防哭相
- 1.2–3.5s：「都会」— 半开，圆唇不足，气声
- 3.5–5.0s：「好起来」— 句尾渐闭，颏肌 6/10 抖

### 表情·肌肉

- L1：疲惫 U6 下垂 2/10
- L2：悲伤 P3 5/10，U5 眶部 5/10
- L3：安慰面具 M1 3/10 与 L2 矛盾

**瑕疵：** 句中 2.1s 右眼先眯；鼻翼左侧扩张；吞咽动作 3.8s

## 示例 3：心虚偷看

**用户输入：**「做坏事被抓包前那种心虚眼神。」

- L2：水平眼动 2 次（0.4s、1.1s），每次 15° 不回头
- U2 2/10 + P2 单侧 3/10
- 无大笑；M1 0–1
- 瑕疵：下唇 P4 轻颤 0.8Hz；肩可选 1/10

### 帧级（4s）

0–0.8s 静止 → 0.8–1.6s 第一次眼动 → 1.6–2.4s 定格 → 2.4–3.2s 第二次眼动 → 3.2–4s 口型微张吸气
